# 케셰브 한 장 실행 안내 (처음 보는 사람용)

Windows PC에서 보안 Agent 앱 **케셰브**를 켜고, 내 PC 상태를 확인하고, 끄는 방법입니다. 이 한 장만 보고 따라 할 수 있게 썼습니다.

## 준비 (한 번만)

1. **Node.js 22~24** 를 설치합니다(수업 기준 24.19.0). 설치 뒤 PowerShell 창을 새로 엽니다. 확인: `node -v` → `v22`~`v24` 로 시작하면 됩니다.
2. **Git** 이 있으면 아래처럼 받습니다. (없으면 GitHub 저장소 화면의 Code → Download ZIP 으로 받아 압축을 풉니다.)

```powershell
cd $HOME
git clone https://github.com/lhw3740-design/Keshev.git keshev
```

`npm install` 은 필요 없습니다(외부 패키지가 없습니다).

## 켜기

1. 파일 탐색기에서 받은 폴더 안의 **`on-client`** 폴더를 엽니다.
2. 주소 표시줄에 `powershell` 을 입력하고 Enter → 그 폴더에서 PowerShell 창이 열립니다.
3. 아래 한 줄을 붙여 넣고 Enter:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

4. 창에 **`케셰브가 켜졌습니다. 브라우저에서 http://127.0.0.1:5189/ 을 여세요.`** 가 보이면 성공입니다. (`참고: 지금 Node.js 는 …` 줄은 버전 안내일 뿐이며 계속 진행됩니다.)
5. 브라우저 주소창에 **`http://127.0.0.1:5189/`** 를 엽니다.

## 써 보기 (핵심 기능 3가지)

| 순서 | 어디서 | 누를 것 | 보이는 것 |
|---|---|---|---|
| 1 | 「보호 현황」 → 「학생 상태·알림 표시」 칸 아래 **내 PC 상태** | 「내 PC 상태 조회」 | CPU·메모리·디스크 실측값, 잰 시각·방법 (타일의 「자세히」를 펼치면 세부 값) |
| 2 | 같은 패널의 **네트워크·방화벽·Windows 기록** 타일 | (1번에서 함께 조회됨) | 인터넷 연결 여부, 방화벽 프로필별 켜짐/꺼짐, 최근 24시간 오류·경고 건수. 못 읽으면 「? 확인 불가」 |
| 3 | 「보안 기록」 메뉴 | 기록의 「상세」, 「AI 설명 요청」 | 보안 기록과 근거·규칙, AI 설명(참고용). 실제 회사 시스템이 연결되지 않은 기본 실행에서는 「연결 없음」·「확인 불가」가 정상입니다 |

- 값을 새로 재려면 「다시 조회」를 누릅니다. 자동으로 반복 조회하지 않습니다.
- 조회 중 멈추려면 「조회 취소」. 취소한 조회의 늦은 결과는 화면에 나오지 않습니다.
- 상태 표시: **● 정상**, **▲ 주의**(점검 권장일 뿐 장애 판정 아님), **? 확인 불가**(값을 읽지 못함 — 정상이나 0으로 보지 않음).

## 끄기와 다시 켜기

- **끄기**: 앱을 켠 PowerShell 창에서 `Ctrl+C`.
- **다시 켜기**: 같은 `on-client` 폴더에서 「켜기」 3번 명령을 다시 실행.

## 막혔을 때

| 보이는 메시지 | 할 일 |
|---|---|
| `Node.js 가 없습니다` / `지금 Node.js 는 vXX` | Node.js 22~24 설치 후 PowerShell 창을 새로 열고 다시 실행 |
| `포트 5189 를 다른 프로그램이 쓰고 있습니다` | 명령 끝에 ` -Port 5190` 을 붙여 실행하고 브라우저도 `:5190` 으로 엽니다 |
| `앱 폴더가 아닙니다` | `on-client` 폴더 안에서 실행했는지 확인 |
| 브라우저에서 주소가 안 열림 | PowerShell 창이 아직 켜져 있는지 확인(닫았으면 다시 켜기) |
| 내 PC 상태 「조회 실패」 | PowerShell 창의 오류 확인 → 「다시 조회」. 계속되면 「도움정보 불러오기」 결과를 담당자에게 전달 |
| 방화벽·기록만 「확인 불가」 | 그 PC의 정책·권한으로 읽기가 막힌 경우입니다. 설정을 바꾸지 말고 그대로 둡니다 |
