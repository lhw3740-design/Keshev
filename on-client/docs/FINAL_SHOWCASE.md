# 케셰브 완성본 시연과 한계 정리 (마지막 총공세, 학생 작성)

22단계까지 만든 앱을 내 PC에서 매일 쓰는 앱으로 다듬은 결과입니다. 되는 것과 안 되는 것을 근거와 함께 적었습니다.

근거 표기: **실제 실행** = 학생 Windows PC에서 앱을 켜고 화면에서 확인, **모의 점검** = 모의 입력으로 함수 출력만 확인, **원문 확인** = 코드만 읽고 맞춘 것, **미확인** = 확인하지 않음.

## 1. 핵심 기능 3가지와 화면 틀

| # | 핵심 기능 | 화면 위치 | 제공/직접 |
|---|---|---|---|
| 1 | **내 PC 상태** — CPU·메모리·디스크를 이 PC에서 실제로 재고 잰 시각·방법 표시 | 보호 현황 → 학생 상태·알림 표시 칸 아래 「내 PC 상태」 | **직접 개선**: 시작 틀 0.2.14 에는 제공된 ‘내 PC 상태’가 없어 학생이 새로 만듦 |
| 2 | **네트워크·방화벽·Windows 기록** — 읽기 전용, 못 읽으면 확인 불가 | 같은 패널의 네트워크·방화벽·Windows 기록 타일 | **직접 개선** |
| 3 | **보안 기록·AI 설명** — 기록의 근거·규칙·확인 불가 상태와 AI 설명(참고용) 대조 | 보안 기록 메뉴 | 화면 틀·요청은 제공, 표시 함수는 13~20단계 학생 구현 |

학생이 고른 중점은 3번(보안 기록·AI 설명)이며, 1·2번은 권장 일정 2~3일차를 학생 전용 모듈로 구현하기로 학생이 정했습니다. 화면 틀은 **관제 대시보드형**(상태 타일을 먼저, 세부는 접어 둠)입니다.

## 2. 제공 부분과 직접 개선한 부분

| 파일 | 구분 | 내용 |
|---|---|---|
| `src/student-pc/collector.mjs` | 학생 작성(새 파일) | Node `os`·`fs.statfs` 와 읽기 전용 PowerShell(`Get-NetConnectionProfile`, `Get-NetFirewallProfile`, `Get-WinEvent` 건수만)으로 값 수집. 실패는 `status:'unavailable'` + 이유 코드, 명령마다 6초 제한 |
| `src/server.mjs` | 제공 파일에 **학생 추가 7줄** | `// [학생 추가]` 표시한 import 1줄과 `GET /api/student/pc-status` 경로만 추가. 다른 제공 코드는 그대로 |
| `student/extension.mjs` | 학생 작성 | `createPcPanel()` 과 `renderStatus` 끝에 패널 연결. 조회·다시 조회·조회 취소, 세대 번호로 늦은 응답 차단, 9초 제한 |
| 그 밖의 `public/*`, `src/*`, `tools/*` | 제공 | 수정하지 않음 |

`public/app.js`·`public/style.css` 는 고치지 않았습니다. 패널의 배치는 학생 파일 안에서 요소의 `style` 로 지정했습니다. 설치형 앱(워크벤치 승인 실행 환경)에서도 같은 모양인지는 **미확인**입니다.

## 3. 시연 순서 (약 3분)

1. `on-client` 에서 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1` → 창의 「케셰브가 켜졌습니다」 확인.
2. 브라우저 `http://127.0.0.1:5189/` → 위쪽 「연결 없음」 표시가 회사 시스템 미연결 기본 상태임을 설명.
3. 「내 PC 상태 조회」 → 여섯 타일(CPU·메모리·디스크·네트워크·방화벽·Windows 기록)과 ● 정상 / ▲ 주의 / ? 확인 불가, 「자세히」의 잰 시각·방법을 보여 줌.
4. 「다시 조회」 → 잰 시각이 바뀌는 것을 보여 줌. 조회 중 「조회 취소」 → 「조회 취소됨」 후 늦은 결과가 나타나지 않음을 보여 줌.
5. 「보안 기록」 메뉴 → 기본 실행에서는 기록이 「확인 불가」로 남는 이유(실제 회사 시스템 미연결)를 설명. AI 설명은 참고용이며 조치를 실행하지 않는다는 점을 설명.
6. PowerShell 창에서 `Ctrl+C` → 브라우저가 열리지 않는 것 확인.

| 기능 | 상태 | 이유·근거 |
|---|---|---|

## 6. 안전·정직성 원칙

- 수집 명령은 모두 읽기 전용입니다. 방화벽·설정을 바꾸는 명령은 없습니다.
- 이벤트는 건수만 세고 본문을 읽어 오지 않습니다. MAC 주소·사용자 이름은 돌려주지 않습니다.
- 설명용 예시 값을 화면에 넣지 않습니다. 못 읽은 값은 「확인 불가」로 남깁니다.
- 「▲ 주의」 기준은 학생이 정한 값이며(CPU·메모리 90% 이상, 디스크 남은 공간 10% 미만, 꺼진 방화벽 프로필, 인터넷 연결 프로필 없음, 기록 오류 1건 이상) 장애 판정이 아닙니다.
- 이 버전은 **검증 중인 버전**이며 v1.0 이나 운영 인증이 아닙니다.
